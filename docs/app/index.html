      Modes

      • Browse — view the schema of any version (working tree, a branch, a commit) and filter it. Nothing is checked out.
      • Compare — what changed between two versions. Compare… has the common cases: uncommitted changes, last commit, this branch vs main, a colleague's branch, a specific commit. ↻ fetch picks up branches others pushed.
      • Design — sketch new tables and changes on top of the schema and export a spec (Markdown, SQL, JSON or a prompt) for an agent; schema design check NAME verifies the result.

      Diagram

      • Drag the background to pan, drag a table to move it · scroll to pan · ⌘/Ctrl + scroll or pinch to zoom
      • Click a table for details (a column typed with an enum opens the enum) · double-click to show only it and its neighbours
      • Right-click a table for filtering, columns and (when designing) editing · hover to highlight its relations

      Filtering

      • Type a table or pattern (card*) in the bar above the diagram; each chip shows its neighbours up to the depth on it (−/+)
      • In Compare, the purple Changed tables chip limits the view to what changed; × shows everything with the changes highlighted, + my filters combines both
      • Click N of M tables to see what is hidden and why

      Keyboard

      • / search · f fit · +/- zoom · 0 100% · 1–5 layouts · k column modes · e edge styles · c only changes
      • Esc close details / show everything / clear the filter · designing: n new table, ⌘Z undo

      Legend

      • PK primary key · FK foreign key · UQ unique · ? nullable
      • added · removed · changed (types show old → new)
      • Crow's foot = "many" side, bars = "exactly one", circle = optional
      • Dotted edges: inferred relations and enum use · dashed edges: view dependencies · lines hop where they cross
      • ↗N relations to hidden tables · +NP hidden partitions · … N more columns click to expand

      Display

      Display ▾ in the top bar holds layout, columns, edges and objects; rarely needed settings sit under Advanced. Everything is remembered per file. Save named views to .schema.json (Export menu) and open them with schema --view NAME.

      From the command line

      schema browses · schema --at origin/feature browses a branch · schema main...feature or schema HEAD~1 compares · schema --design NAME designs.
