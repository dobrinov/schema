      Mouse

      • Drag background to pan, drag a table to move it
      • Scroll to pan (trackpad) · ⌘/Ctrl + scroll or pinch to zoom
      • Click a table for details · double-click to focus on it
      • Right-click a table or column for more actions
      • Hover to highlight its relations

      Keyboard

      • / search · f fit · +/- zoom · 0 100%
      • 1–5 layout algorithms · c only changes
      • k cycle column modes · e cycle edge styles
      • Esc clear selection / focus

      Legend

      • PK primary key · FK foreign key · UQ unique · ? nullable
      • added · removed · changed
      • Crow's foot = "many" side, bars = "exactly one", circle = optional
      • Dotted edges are inferred, dashed edges are view dependencies
      • ↗N relations to hidden tables · +NP hidden partitions

      Config

      Everything you change is remembered per file. Save named views to .schema.json and open them with schema --view NAME.
